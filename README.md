# Depth-Routing Attention

Reference implementation of the paper **Depth-Routing Attention: Sparse Attention
with Learned Depth Budgets** (KDD 2026, arXiv:2605.09111).

The method learns a routing matrix that selects a sparse set of attention edges at
each layer. It is evaluated on node classification and link prediction.
